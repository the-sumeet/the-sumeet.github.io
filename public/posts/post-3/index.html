Post 3: Markdown Feature Showcase

March 15, 2023

This post serves as a comprehensive showcase of Markdown syntax, typography elements, and formatting features supported by Hugo and the smpl theme.

Typography & Inline Formatting

Markdown allows rich inline text styling for readability and emphasis:

  • Bold text: **bold** renders as bold text
  • Italic text: *italic* or _italic_ renders as italic text
  • Bold & Italic: ***bold & italic*** renders as bold and italicized text
  • Strikethrough: ~~strikethrough~~ renders as deleted or struck-through text
  • Inline Code: `const answer = 42;` renders as const answer = 42;
  • Highlighted text: <mark>highlighted</mark> renders as highlighted text
  • Keyboard shortcuts: <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> renders as Ctrl + Shift + P
  • Superscript & Subscript: H<sub>2</sub>O renders as H2O, and E = mc<sup>2</sup> renders as E = mc2
  • Hyperlinks: Hugo Website and auto-linked URLs like https://github.com.

Headings Hierarchy

Organizing content into semantic heading levels provides clean structure:

Heading Level 3

Paragraph introducing a subtopic under heading 3. It flows naturally into subsections and provides clear visual separation.

Heading Level 4

Detailed subsection covering specific points or technical breakdown.

Heading Level 5

Fine-grained point or parameter breakdown.

Heading Level 6

Lowest-level heading, useful for minor notations or dictionary definitions.

TypeScript / JavaScript

interface UserProfile {
  id: string;
  username: string;
  isActive: boolean;
  roles: string[];
}

function formatGreeting(user: UserProfile): string {
  const greeting = user.isActive ? "Welcome back" : "Hello";
  return `${greeting}, ${user.username}! (Roles: ${user.roles.join(", ")})`;
}

const currentUser: UserProfile = {
  id: "usr_101",
  username: "alex_dev",
  isActive: true,
  roles: ["admin", "editor"],
};

console.log(formatGreeting(currentUser));

Python

from dataclasses import dataclass
from typing import List

@dataclass
class Article:
    title: str
    tags: List[str]
    word_count: int

    @property
    def reading_time_minutes(self) -> float:
        """Estimate reading time based on average 200 WPM."""
        return round(self.word_count / 200, 1)

post = Article(title="Markdown Deep Dive", tags=["web", "hugo"], word_count=1250)
print(f"'{post.title}' estimated reading time: {post.reading_time_minutes} min")
